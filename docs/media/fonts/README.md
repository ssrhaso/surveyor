# Fonts

`texgyreheros-regular.otf` and `texgyreheros-bold.otf` are the TeX Gyre Heros
family (based on URW Nimbus Sans, metrically compatible with Helvetica) by
B. Jackowski and J. M. Nowacki, distributed by the GUST e-foundry under the
GUST Font License (a free license; LPPL with additional permissions):
https://www.gust.org.pl/projects/e-foundry/tex-gyre

They are vendored here so `make_surveyor_overview.py` renders identically on
any machine, without depending on system fonts.
